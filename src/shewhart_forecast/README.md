# Shewhart Forecast Module

Модуль прогнозирует момент выхода концентрации газа за верхнюю границу контроля (UCL).

## Функциональность
- Вычисление CL, LCL, UCL.
- Построение линейного тренда по последним 30 точкам.
- Прогноз пересечения UCL.
- Оценка риска выхода за контроль.
- Анализ только первых 5 объектов.

## Запуск
python main.py


## Вывод
Для каждого газа:
- UCL
- Статус тренда
- Шаги до выхода за UCL
