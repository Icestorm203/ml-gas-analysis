# Shewhart Charts Module

Этот модуль строит карты Шухарта для газов трансформатора (H2, CO, C2H4, C2H2).

## Функциональность
- Вычисление CL, LCL, UCL для каждого газа.
- Поиск точек вне контроля.
- Построение графиков Шухарта.
- Сохранение графиков в PNG-файлы.
- Анализ первых 5 объектов.

## Структура данных
Ожидается структура:
```
data/
 ├── train.csv
 └── data_train/
      ├── <id1>.csv
      ├── <id2>.csv
      └── ...
```

## Запуск
python main.py

Графики сохраняются в:
data/shewhart_charts/<object_id>/
