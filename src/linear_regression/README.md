# Linear Regression + Logistic Regression + CatBoost

Модуль выполняет двухэтапную обработку данных:
1. Поиск выбросов через логистическую регрессию.
2. Регрессионное предсказание через CatBoost.

## Возможности
- Загрузка временных рядов.
- Извлечение признаков TSFresh.
- Бинаризация целевой переменной для поиска выбросов.
- Логистическая регрессия для детекции выбросов.
- Коррекция выбросов в прогнозе CatBoost.
- Построение гистограммы истинных и предсказанных значений.

## Запуск
python main.py


## Результат
- F1‑score для детекции выбросов.
- MAE train / MAE val после коррекции.
- Гистограмма сравнения предсказаний и истинных значений.
