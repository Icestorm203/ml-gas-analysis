# Shewhart + CatBoost Hybrid Diagnostics

Модуль объединяет статистический контроль (Шухарт) и ML‑модель CatBoost для диагностики состояния трансформатора.

## Возможности
- Извлечение признаков TSFresh.
- Быстрый подбор гиперпараметров CatBoost (RandomizedSearchCV).
- Прогноз RUL (остаточного ресурса).
- Обнаружение аномалий по Шухарту.
- Гибридная классификация состояния:
  - Нормальный режим
  - Умеренная деградация
  - Критическое снижение RUL
  - Аномалия по Шухарту

## Запуск
python main.py


## Результаты
- MAE train / val
- Флаги аномалий
- UCL для каждого газа
- Прогноз RUL
- Итоговый статус объекта
